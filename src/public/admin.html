Preload run

Warms the caches by calling this instance for every selected domain. The run is a separate process, so it survives page reloads and is visible from every worker. Raise the timeout above the default 30000 ms for slow sites — 60000 suits a scheduled run; domains that exceed it are logged as This operation was aborted.
